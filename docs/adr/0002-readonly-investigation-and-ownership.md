# ADR 0002: 읽기 전용 조사와 현재 서비스 소유 팀 연결

- 상태: 목표 설계에 채택; 구현 전
- 날짜: 2026-10-08

직원 문의에 문서 안내만 제공하는 범위에서 시스템 관측 근거를 조사하는 범위로 확장한다. Python 단일 Agent가 조사 도구를 선택하고 Spring Gateway가 매 호출의 권한·조회 범위·예산을 검증한다. 업무 DB·로그·배포 코드 읽기는 허용된 도구 계약으로 제한하며 임의 SQL·명령 실행·데이터 변경·코드 배포는 제공하지 않는다.

RAG는 업무 정의와 조치 절차를 찾고, 실제 관측값과 실행 코드 확인은 version/snapshot을 가진 읽기 도구로 수행한다. DeskMate 저장 DB와 조사 대상 업무 DB를 구분한다. 사실·원인 후보·미확인 항목을 분리해 답변하고 전문 조치가 필요하면 승인 후 티켓을 만든다.

담당자는 현재 서비스 소유 팀 registry로 찾는다. Git 작성자/변경 이력은 기술 근거로 사용하며 책임자 배정 정답으로 사용하지 않는다. 소유 팀이 없거나 충돌하면 미할당 큐로 접수한다.

이 선택은 권한·Gateway·서비스 매핑·fixture 제작 부담을 추가한다. 직접 Python 업무 DB 연결과 최초 작성자 자동 배정 대안보다 권한 경계를 일관되게 유지하고 담당자 변경에 대응할 수 있다. 정상/거부/timeout/버전 불일치와 잘못된 소유 팀 사례를 평가한다. 실제 연결과 성능 검증은 수행 전이다.
